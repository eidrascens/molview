# MolView

A Mol* GTK4 + Libadwaita interface for native-looking and
consitent UI/UX molecular structure view in GNOME desktop
environment.

# LLM Use

Unfortunately and shamefully, an LLM was used to generate
a proof-of-concept (see `molview-gnome`[./molview-gnome])
of this program. Rest assured, however, that a human refactored
and programmed the entire application `src`[./src] with
neither help nor assistance of any LLM nor whatsoever.

## How the AI Was Used?

Undeniably, the use of AI in any way or form is unacceptable.
But answering the question without trying to excuse myself,
the AI used in drafting the proof-of-concept was minimal.
It was generated by asking ChatGPT Web UI whether if it is
possible to integrate Mol* in a GTK4 + Libadwaita application.
From there ChatGPT generated / drafted the proof-of-concept
one can check in `molview-gnome`[./molview-gnome] folder.
